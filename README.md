# Project README

A fast, modern web application built for transforming urban compliance with AI detection, AR verification, and citizen-powered reporting for safer, compliant cities.

---

## Getting Started

Clone the repository and start the development server:

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
