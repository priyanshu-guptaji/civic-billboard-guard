# 🏙️ Civic Billboard Compliance System

A fast, modern web application designed to **transform urban billboard compliance** using **AI detection, AR verification, and citizen-powered reporting** — helping cities become safer, cleaner, and regulation-compliant.

---

## 🚀 Overview

Urban areas often face issues with **illegal hoardings, unsafe billboards, and outdated permits**.
This project enables **citizens, authorities, and city planners** to collaboratively detect and manage billboard compliance using AI and AR technologies.

---

## ✨ Features

* 🤖 AI-powered billboard detection
* 🧭 AR-based on-site verification
* 📍 Geo-tagged citizen reporting
* 📸 Image upload & compliance analysis
* 🏛️ Authority dashboard for approvals
* 🚨 Illegal billboard flagging
* 📊 Real-time compliance tracking
* 🌐 Modern responsive UI

## 📦 Getting Started

Clone the repository and start the development server:

```bash
git clone https://github.com/<your-username>/civic-billboard-guard.git
npm install
npm run dev
```

App will run on:

```
http://localhost:8080
```
